# Linked List

Implementations and practical problems on Singly Linked Lists (SLL) and Doubly Linked Lists (DLL) in C++.

## Problems Directory

| Folder | Problem Description | Data Structure | Key Operations / Concepts |
| :--- | :--- | :--- | :--- |
| **Q1** | Text Editor Action History | Doubly Linked List (DLL) | Fixed-capacity action history, add action (evicts oldest on limit), search by ID, display |
| **Q2** | College Admission Management System | Singly Linked List (SLL) | Dynamic applicant addition, full list traversal, bubble sort by Applicant ID |
| **Q3** | Railway Waiting List Management | Singly Linked List (SLL) | Queue simulation: add at rear, remove from front on confirmation, search, display |
| **Q4** | Browser Tab Management System | Doubly Linked List (DLL) | Add tabs, move backward/previous tab navigation, search tab by URL, display |
| **Q5** | Train Coach Management System | Doubly Linked List (DLL) | Insert at front/rear/position, remove coach, search coach number, reverse display (rear to engine) |
| **Q6** | Music Player Playlist | Singly Linked List (SLL) | Add songs, remove songs, display playlist, play specific song |
| **Q7** | Library Catalogue Management System | Singly Linked List (SLL) | Add book, remove book, display available books, search book by ID |
| **Q8** | Social Media Post Feed | Doubly Linked List (DLL) | Chronological sorted insertion by timestamp, delete post, search by ID, newest to oldest display |
| **Q9** | Student Attendance Management System | Singly Linked List (SLL) | Add student, remove student, display all student records, search by roll number |
| **Q10** | Hospital Patient Consultation Queue | Singly Linked List (SLL) | Patient registration, consult & remove patient, queue traversal, search by ID |

## Build & Run

To compile and run any problem (for example, Q1):

```bash
cd Q1
g++ main.cpp history.cpp -o solution
./solution
```

For other problems, compile `main.cpp` together with the respective `.cpp` file (e.g., `admission.cpp`, `railway.cpp`, etc.).
